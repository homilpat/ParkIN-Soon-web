# 포트폴리오 실행본 정리 보관 목록

2026-08-26 기준 `kiosk.py` 운영 경로에서 직접 사용하지 않는 자료를 삭제하지 않고 이동했다.

- `training/`: PPMI 전처리, 이미지·운동학 학습, 검증 유틸리티
- `rag_experiments/`: 벡터 DB 구축·복구, RAG 평가 스크립트, 이전 및 v3 평가 질문셋
- `reports/`: RAG 개발·잠금 평가 JSON 결과
- `legacy_assets/`: 이전 단일 이미지 모델, 중복 병원 CSV, 발표용 원본 이미지, 잘못 생성된 빈 파일
- `maintenance/`: 모델 직렬화 이관, 양식 제거, 과거 재부팅 인계 자료

운영에 필요한 RAG 모듈, 모델, 벡터 DB, `hospital_data.xlsx`, 캐릭터 이미지와 테스트는 프로젝트 루트 구조에 유지했다. 보관 파일을 복원하기 전에는 현재 배포 코드의 참조 여부와 개인정보 포함 여부를 다시 확인한다.
