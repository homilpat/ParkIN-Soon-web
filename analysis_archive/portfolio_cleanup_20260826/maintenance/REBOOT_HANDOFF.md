### 내일 가장 먼저 할 일

1. 중단된 침·영양제 안전 규칙 회귀 평가를 다시 실행한다.
   `evaluate_senior_rag.py --ids senior_internal_unknown,senior_supplement`
2. 결과에서 두 문항 모두 의료 경계·기대 행동·필수 내용 `1.0`, 금지 표현 `0.0`인지 확인한다.
3. 자동 채점기가 놓친 효능·완치·예방 주장을 잡도록 평가 스키마에 `unsupported_treatment_claim` 항목을 추가한다.
4. 고령 사용자 평가셋을 개발용과 잠금형으로 분리한다. 오늘 24문항은 이미 수정에 사용했으므로 독립 성능으로 부르지 않는다.
5. 새로운 고령 사용자 잠금셋에는 보호자 질문, 청력·시력 불편, 반복 질문, 복약 혼동, 검사 중단, 글을 읽기 어려운 상황을 포함한다.
6. 정확한 근거가 부족한 일반 질문에 similarity 하나가 아니라 검색·Cross-Encoder·수치/대상 일치도를 결합한 evidence gate를 구현한다.
7. evidence gate가 답변을 거부할 때 고객 화면에는 `등록 논문`, `RAG`, `DB`, `유사도`, `청크`를 노출하지 않는다.
8. 마지막에 전체 Python 문법 검사와 24문항 회귀를 다시 실행하고 실제 답변을 사람이 표본 검토한다.

## 현재 상태

- WSL 2.7.12와 Ubuntu 24.04를 설치하고 일반 사용자 `user`를 기본 사용자로 설정했다.
- 호스트 GPU는 NVIDIA RTX A4000 16GB이며 Windows 드라이버 596.86과 WSL GPU 전달을 확인했다.
- `~/venvs/parksoon-tf`에 TensorFlow 2.21과 CUDA 의존성을 설치했다.
- 설치 파일: `tmp/nvidia/nvidia-rtx-596.86.exe` (약 714 MiB)
- TensorFlow가 RTX A4000을 `GPU:0`으로 등록하고 실제 행렬 곱을 GPU에서 수행하는 것을 확인했다. 실행 시 가상환경의 `site-packages/nvidia/*/lib`를 `LD_LIBRARY_PATH`에 포함해야 한다.
- Windows TensorFlow 2.20은 Java/Oracle 경로에 포함된 오래된 VC 런타임 DLL과 충돌했다. 해당 PATH를 제외하면 CPU import와 연산은 성공했다.
- Windows 네이티브 TensorFlow 2.11 이상은 CUDA GPU를 지원하지 않으므로 이후 학습은 WSL2에서 진행한다.

## 데이터와 코드

- UCI Parkinson Spiral 원본: 77명(파킨슨병 62명, 건강 대조군 15명), txt 79개와 png 50개를 `data/external/UCI_395`에 받았다.
- HandPD Spiral: 실제 이미지 368개와 메타데이터 368행을 받았으며 정확한 해시 중복은 없다.
- HandPD 그룹 키는 `CLASS_TYPE + ID_PATIENT`로 잡아야 한다. 확인된 고유 그룹은 건강 대조군 18명, 파킨슨병 36명이다.
- 외부 데이터는 `.gitignore`의 `data/external/` 규칙으로 Git에서 제외된다.
- `train_spiral_grouped.py`(173줄)를 추가했다. MobileNetV2 고정 특징 + 가중 Logistic Regression, 피험자 그룹 단위 nested CV, 기존 28명 데이터 외부 평가 구조다.
- 원본 CNN과 학습 전용 증강을 복원해 다시 실행했다. HandPD 그룹 OOF AUC는 0.8858이고 기존 28명 외부 평가에서 민감도 0.80, 특이도 0.4615였다.
- 외부 정상군 오탐이 13명 중 7명으로 많아 후보를 배포하지 않았다.
- MobileNetV2 전체 동결, `32→1` 헤드, 강화 L2, 5-fold 앙상블로 용량을 제한한 후보는 외부 AUC 0.7436, 민감도 0.8667, 특이도 0.5385였다.
- 증강 노출 3배 후보는 외부 AUC 0.7179, 민감도 0.80, 특이도 0.6154로 1배 후보보다 선별 민감도가 낮았다.
- HandPD와 기존 데이터를 합친 82명·470장 실험은 출처×클래스 층화 피험자 기준으로 개발 65명과 내부 홀드아웃 17명으로 분리했다. 개발 OOF AUC는 0.840447, 내부 홀드아웃 AUC는 0.885714, 민감도는 0.90, 특이도는 0.571429였다.
- 내부 홀드아웃 결과를 이미 확인했으므로 후속 후보 선택에서 독립 외부평가로 부르지 않고 탐색적 내부평가로만 기록한다.
- HandPD 368장에는 OpenCV를 적용해 검정 가이드 주변의 파란 사용자 궤적만 추출하고 흰 배경·검정선으로 통일했다. 빈 변환 결과는 없었다.
- 5% 가이드 통로 보정의 원본 파란 마스크 대비 중앙 IoU는 0.754525였다. 건강군 평균 IoU 0.7753, 파킨슨병군 0.7211로 환자군 이탈선을 더 제거할 가능성이 있어 폭 설정은 아직 확정하지 않았다.
- 파란색을 검정색으로 바꾸는 것은 색상·배경 도메인 차이를 줄이는 보정이며, 선 굵기·해상도·스캔 장비 차이까지 제거하는 완전한 도메인 적응은 아니다.
- trace-only HandPD를 사용한 통합 OOF 재학습은 아직 실행하지 않았다.
- 모든 그림 후보는 `modeling/candidates/`에만 있으며 서비스 배포 모델과 Fusion 설정은 유지했다.
- 후보 산출물은 `modeling/candidates/`에 보존하며 이미지 AUC·임계값과 Late Fusion 설정은 기존 배포값을 유지한다.

## 재부팅 직후 순서

1. trace-only HandPD의 저-IoU 이미지와 클래스별 무작위 샘플을 확인하고 통로 폭별 클래스 보존율을 비교한다.
2. trace-only HandPD와 기존 데이터를 합쳐 출처×클래스 층화 80:20 피험자 분할을 재현한다.
3. 개발 80%에서 피험자 단위 5-fold OOF를 수행하고 OOF에서만 임계값을 정한다.
4. 전체 및 출처별 성능과 fold 편차를 기록하고 원본 통합 후보와 탐색적으로 비교한다.
5. 새 독립 피험자 검증 전에는 서비스 모델, 이미지 임계값 및 Late Fusion 설정을 변경하지 않는다.

## 유지할 원칙

- 분할 단위는 이미지가 아니라 피험자다.
- 평가 fold나 외부 평가 세트로 특징 선택·임계값 선택·가중치 선택을 하지 않는다.
- 점수는 동적 Late Fusion, 단계 판정은 유효 검사 2개 이상에서 다수결을 사용한다.
- 결과는 진단 확률이 아니라 파킨슨병 위험군 선별 결과로 표현한다.
- 논문 RAG는 논문 본문 우선 청킹, 참고문헌 제외, `BAAI/bge-m3` 임베딩을 유지한다.
